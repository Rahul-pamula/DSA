SECTION 2 ANSWERS

Q21. == doesnt compare array content. Use Arrays.equals(a, b)
Q22. i <= nums.length causes nums[i+1] to go out of bounds. Use i < nums.length - 1
Q23. Arrays not sorted before comparing! Add Arrays.sort(a) and Arrays.sort(b) first
Q24. When i=0, runningSum[i-1] = runningSum[-1] = out of bounds!
     Fix: set runningSum[0]=nums[0] before loop and start from i=1
Q25. Missing return false - method has no return if no duplicate found
Q26. ans array size is nums.length but needs 2*nums.length. Will get ArrayIndexOutOfBoundsException
Q27. Missing second loop to fill remaining positions with 0 after j
Q28. return is not assignment. Remove the = sign. Use: return true
Q29. Last element placed at nums[j] but j not incremented. Should be j++ then return j
Q30. Strings dont have .sort() method. Convert to char array, then Arrays.sort()
Q31. Strings use length() with parentheses, not length
Q32. Loop starts at i=0 but runningSum[0] already set. Loop should start at i=1
Q33. result=false in else overwrites previous true result.
     Fix: return true immediately when found. return false after loop.
Q34. Missing last element handling!
     After loop: nums[j] = nums[nums.length-1]; j++;
Q35. Method doesnt exist. Use Arrays.equals(a, b) to compare arrays
