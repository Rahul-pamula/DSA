# 🚀 30-Day DSA Consistency Challenge

*Discipline is just choosing between what you want now and what you want most.* 

Goal: Write code and solve at least ONE DSA problem every single day for 30 days.

## The Rules of the Challenge
1. No Zero Days: Open your IDE and write one line of code, or review one problem. A 5-minute day is better than a 0-minute day.
2. Track It: Check off the box here every time you complete a day (change [ ] to [x]).
3. Use the Cheat Sheet: Rely on the dsa_syntax_roadmap.txt to avoid getting stuck on syntax.

## 💡 Daily Checklist for Solving a Problem
1. Did I understand the problem statement?
2. Did I think of a brute force solution first?
3. Did I try to optimize it?
4. Did I write the code and handle edge cases?
5. (Crucial) If I got stuck for more than 45 minutes, did I look at the solution, understand it, and code it myself?
