## 🧠 Learning Philosophy

> ❌ Don't: Rush to solve 10 problems a day just for count
> ✅ Do: Solve 8 problems a day but truly understand each one

**After every problem ask yourself:**
1. Can I explain this in plain English?
2. What pattern does this use?
3. What is the time & space complexity?
4. Can I code it again without looking?

If yes to all 4 → move on. If not → solve it again tomorrow ⭐
